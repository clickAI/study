# Goal
책 대여 구독 서비스 웹사이트를 디자인한다.

# Requirments

1. Vercel에 배포할 수 있도록 git으로 관리한다.
2. 백엔드 없는 정적 홈페이지로 개발한다.
3. 절대 이미지 다운로드 목적 외에 다른 홈페이지의 디자인을 직접 참고하지 않는다.
4. 최대한 아래 디자인 요구사항에 맞게 개발한다.
5. 문구나 색상, 위치 등 표현이 모호한 경우는 자율적으로 채우되 추가 요소를 넣을 땐 항상 허가를 받는다.
6. 배경화면은 주어진 banner.png 를 사용한다.
7. 실제 내부 기능은 구현하지 않는다.
